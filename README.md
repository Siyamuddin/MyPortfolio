# Siyam Uddin

Portfolio for web development and AI automation. Public pages use Supabase when it is configured, and static data otherwise.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy [`.env.example`](.env.example) to `.env.local` and fill the values.

```bash
npm test
TEST_DATABASE_URL=postgresql://localhost/portfolio_test bash scripts/test-database.sh
```
